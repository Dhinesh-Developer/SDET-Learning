Software Testing:
----------------
    - The process of identifying defects in software to ensure quality before releasing it to customers or clients

Manual Testing:
---------------
    - Testing that is carried out manually by a human tester without the use of automation tools.

    Types:
    1. Re-testing - Testing the same functionality after defects have been fixed
    2. Regression testing - Testing to ensure that new changes do not negatively affect existing functionality

    Challenges:
    1. Time = Manual testing is often slow
    2. Effort = It requires considerable human Effort

Automation Testing:
-------------------
     - using the third-party tool for testing
    - Testing that uses automation tools to execute tests

    Key points:
    -   How automation tools work: Automation tools require scripts, written in programming languages, to define and execute tests
    - Why programming is required: Programming is essential to automate test cases, handle complex scenarios, and integrate with other testing tools

What is selenium? Selenium automates browsers
-----------------
    - Selenium is a popular, open-source tool for automating web applications
    - Selenium was originally developed by Jason huggins in 2004 at Thoughtworks

    Features:
        Open source - Free to use and modify

    Components:
        - IDE - IDE for creating test cases
        - WebDriver - A programming interface to create and execute browser based automation scripts
        - Grid: Allows running tests on Different machines and browsers simultaneously.    


Types of Applications:
----------------------
    1. Desktop applications - software installed on personal computer
    2. Web applications - Software accessed though a web browser
    3. Mobile applications - Software designed for mobile devices like smartphones and tablets

    Advantages of selenium:
    -----------------------
        1. open source and free : No licensing costs
        2. cross-platform support : Workds on multiple operating systems
        3. Browser compatibility - compatible with many browsers (eg: chrome, firefox, edge)
        4. multiple Language support - java,python,c#,Java script
        5. Integration - Can be integrated with third-party tools for enhanced functionality

    Disadvantages:
    -------------
        1. Limited support for windows-based applications - requires additional tools like Autoit, Sikuli, or Robot API.
        2. No native reporting: Needs external tools like TestNG or Extent reports for reporting
        3. Cannot directly handle Excel files: Requires librariews like Apache POI.
        4. Limited support for complex UI elements: Struggles with handling graphs and CAPTCHA.
