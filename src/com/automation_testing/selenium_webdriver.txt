Selenium WebDriver:
-------------------
1. Webdriver is one of the component in selenium
2. WebDriver is a java interface
3. WebDriver is an API (Application programming interface)

WebDriver(I) --- RemoteWebDriver(C) --- ChromeDriver, FirefoxDriver, EdgeDriver etc..

What is an API?
 Application Programming interface

Envirnoment Setup:
----------------- 

Approach:

Not recommended
1. Downloading jars files and attaching them to java project. (Manually) 
    java project ---> jars
- created new java project
- downloaded webdriver jars(.zip) and extracted
- attach jars to java project

recommended
2. Creating Maven project
   

    - created a new maven project in eclipse
    - added webDriver dependency in pom.xml -- Updated
    - how to update -> right click project -> go to maven -> update project -> click ok
     - pom.xml -> add the dependencies
    https://mvnrepository.com/

<dependencies>
	  <!-- Source: https://mvnrepository.com/artifact/org.seleniumhq.selenium/selenium-java -->
    <dependency>
        <groupId>org.seleniumhq.selenium</groupId>
        <artifactId>selenium-java</artifactId>
        <version>4.49.0</version>
        <scope>compile</scope>
    </dependency>
</dependencies>
