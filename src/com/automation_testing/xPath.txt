
XPath - XPath is an address of the elements

Document object model

Two types of XPath:
1. Absolute xpath (full xpath)
    - copy full xpath
    Ex: /html/body/header/div/div[2]/div/input
    /html/body/header/div/div/div[2]/div/input

2. Relative xpath (partial xpath)
    - copy xpath
    Ex: //*[@id="search"]/input
    * -> means tag Name
    //*[@id="search"]/input


which xpath will be preferred?
Relative xpath.

Difference between Absolute and Relative xpaths?

1. Absolute xpath starts with  / ----? represents root node
    Relative xpath starts with //

2. Absolute xpath do not use attributes
    Relative xpath works with attribute

3. Absolute xpath traverse through each node till it finds elements
    Relative xpath directly jump and find the element by using attribute
