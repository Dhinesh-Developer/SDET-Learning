Introduction

--- Software testing:
 The process of identifying defects in software to ensure quality before releasing it to customers or clients

--- Manual Testing:
 Testing that is carried out manually by a human tester without the use of automation tools.
 Types:
 1. re-testing -> Testing the same functionality after defects have been fixed.
 2. Regression Testing -> Testing to ensure the new changes do not negatively affect existing functionality.

What is software testing ->

What is software quality?
1. Bug-free
2. Delivered on time
3. Within budget
4. Meets requirements and/or expectations
5. Maintainable
	
What is project vs product?
- If software application is developed for [[ specific customer ]] based on the requirement then it is called project
- If software application is developed for [[ multiple customers ]] based on market requirements then it is called product

Error, Bug/defect & Failure
1. error -> incorrect human actions -> ex. developers did some invalid code [normally human mistake]
2. Bug/defect -> deviated from excepted behaviour from the actual behaviour  [mismatch- what our exceptations]
3. Failure -> deviated identified by end user while working with the software is called failure

Why the software has bugs ?
 1. Miscommunication or no communication [requirements mismatch]
 2. Software complexity
 3. Programming errors [responsibility of the developers] unexcepted errors
 4. Changing requirements
 5. Lack of skilled testers
