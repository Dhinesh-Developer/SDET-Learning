-----System Testing Types
1. [GUI testing]
	- Processs of testing the user interface of an application
	- Includes all the elements such as menus, checkbox, buttons, colors, fonts, sizes, icons, content, and images.

2. Usability testing
3. Functional testing
4. Non- functional testing

--- [ GUI Testing checklist ] 
- Testing the size,position,width,height of the elements
- Testing of the error messages that are getting displayed.
- Testing the different sections of the screen
- Testing of the font whether it is readable or not
- Testing of the screen in different resolutions with the help of zooming in and zooming out
- Testing the alignment of the texts and other elements like icons, button, etc. are in proper place or not
- Testing the colors and font
- Testing whether the images had good clarity or not
- Testing the alignment of the images
- Testing of the spelling
- The user must not get frustrated while using the system interface
- Testing whether the interface is attractive or not
- Testing of the scrollbars according of the size of the page if any.
- Testing of the disabled field if any
- Testing of the size of the images
- Testing of the heading whether if is properly aligned or not
- Testing of the color of the hyperlinked
- Testing UI elements like button, textbox, text area, check box, radio buttons, drop downs, links etc

--- [Usability Testing]
	- During the testing validates application provided context sensitive help or not to the user
	- Checks how easily the end users are able to understand and operate the application os called usablitiy testing.
	
--- [Functional Testing]	
	- Funtionality is nothing but behaviour of appliation
	- Functional Testing talks about how your feature should work

- Object properties testing -> check the properties of objects present on the application -> ex. enabled, disable, visible, Focus..
- Database testing/ Backend testing -> DML operations (insert,update,delete,select)  -> GREY box testing [combination of black box and white box testing]
	table level validation [column type,column length, number of cols in data etc], relationship validation [normalization],procedures , function, trigger testing, views, index etc. 
- Error handling ->  tester verify the error messages while performing incorrect actions on the application. error messages should be readle,user understandable/Simple language.
- Calculations/ Manipulations testing -> tester should verify the calculations.  ex. BANk -> withdraw, deposit, check balance -> calculations testing
- Links existence & links execution -> where exactly the links are placed, links are navigating to proper page or not --> Internal links, External links, Broken Links
